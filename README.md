# procurement-allocator

Внутренний веб-инструмент отдела закупок/монтажа Screen Factory Florida:
формирование закупочных ордеров с оптимальным распределением между поставщиками.

Три модуля: обновление БД цен из PDF-прайсов (ИИ-парсинг с ревью), создание проекта
и подбор материалов, распределение закупки между поставщиками (ILP) и генерация ордеров.

## Документация

- `CLAUDE.md` — архитектурные принципы и правила работы над репозиторием.
- `docs/spec.md` — полная продуктовая спецификация.
- `docs/architecture.md` — диаграмма компонентов и потоков данных.
- `docs/data-model.md` — модель данных.
- `docs/glossary.md` — термины домена.
- `docs/decisions/` — ADR (архитектурные решения).
- `docs/design/` — дизайн-референсы экранов (не редактировать вручную).
- `docs/ui-reference.md` — поведенческая логика экранов.
- `docs/DEPLOYMENT.md` — обязательные требования к продовому окружению
  (reverse proxy, `TRUSTED_PROXY_IP`, переменные окружения).

## Структура

```
backend/       — FastAPI-приложение, ILP-сервис, парсинг/матчинг прайсов, БД-модели и миграции
frontend/      — React-приложение (Vite)
docs/          — спецификация, архитектура, ADR, дизайн-референсы
```
