# ADR-0059: В метриках замеров только замерщики из карты

Статус: Принято (2026-11-23). Меняет определение «Замерщик» в ADR-0053 §2.

## Контекст

По ADR-0053 задача-замер, у которой ответственный в amoCRM не из
`measurer_map`, входила в итог компании и в отдельную группу
`measurer_key = null` («Без замерщика»). На практике такие задачи ставят себе
менеджеры (пример — сделка #5151, «Доп. замер» 16.11.2026 на Alissa Sutton),
и это не выезды замерщиков. Руководство считает замерами только работу
замерщиков — сейчас Nazar и Matt Measurement.

## Решение

1. Во всех метриках модуля учитываются только задачи с `measurer_key` не
   `NULL`. Условие одно — `metrics._KNOWN_MEASURER` в общей выборке
   `_rows_cte` и в `list_visits`, поэтому одинаково меняются:
   - итог компании и карточки замерщиков (`/measurements/metrics`), включая
     запланированные, просроченные и показатели качества данных;
   - список визитов (`/measurements/metrics/visits`);
   - ежедневный отчёт бота (`/integrations/measurements/daily-report`,
     ADR-0058) — он на той же выборке.
2. Группа «Без замерщика» из ответов исчезает. Тип задачи (замер, доп. замер,
   встреча) и её результат на исключение не влияют.
3. Синхронизация и пересчёт не меняются: такие задачи по-прежнему читаются из
   amoCRM и хранятся с `measurer_key = NULL`. Исключение — только на уровне
   метрик, поэтому добавление человека в `measurer_map` и пересчёт сразу
   вернут его замеры в статистику, в том числе задним числом.

## Альтернативы

- **Не сохранять такие задачи при синхронизации.** Отклонено: при
  добавлении нового замерщика в карту его прошлые задачи пришлось бы
  дочитывать из amoCRM бэкфиллом; хранение не мешает.
- **Оставить группу, но не включать её в итог компании.** Отклонено:
  руководство просило не учитывать такие задачи вообще.

## Последствия

- Новый замерщик появляется в метриках только после добавления в
  `measurer_map` (конфиг воркера) и пересчёта (ADR-0053 §3).
- Код фронтенда для группы `null` («Без замерщика») остаётся, но API её больше
  не отдаёт.
