# Глоссарий

- **BOM (Bill of Materials)** — список материалов и количеств для проекта.
- **Canonical material** — материал в нашей БД, идентифицируемый по `internal_sku`,
  а не по названию у конкретного поставщика.
- **PriceListEntry** — строка прайса поставщика, распознанная ИИ, ожидающая ревью
  человеком перед попаданием в `Price`.
- **Allocation run** — один расчёт распределения материалов проекта между поставщиками.
- **ILP (Integer Linear Programming)** — метод точной оптимизации, которым решается
  задача выбора поставщика с учётом доставки. См. ADR по алгоритму.
- **Free shipping threshold** — сумма заказа у поставщика, после которой доставка бесплатна;
  влияет на выбор набора поставщиков, а не только на цену позиции.

## Именование

- Технический репозиторий/система: `procurement-allocator`.
- Название в интерфейсе (UI) может отличаться — зафиксируй финальное здесь после решения,
  чтобы не расходилось между кодом, документами и тем, что видит пользователь.
