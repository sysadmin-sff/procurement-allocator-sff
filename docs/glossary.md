# Глоссарий

- **BOM (Bill of Materials)** — список материалов и количеств для проекта.
- **Canonical material** — материал в нашей БД, идентифицируемый по `internal_sku`,
  а не по названию у конкретного поставщика.
- **PriceListEntry** — строка прайса поставщика, распознанная ИИ, ожидающая ревью
  человеком перед попаданием в `Price`.
- **Allocation run** — один расчёт распределения материалов проекта между поставщиками.
- **ILP (Integer Linear Programming)** — метод точной оптимизации, которым решается
  задача выбора поставщика с учётом доставки. См. ADR по алгоритму.
- **Free shipping threshold** — сумма заказа у поставщика, после которой доставка бесплатна;
  влияет на выбор набора поставщиков, а не только на цену позиции.
- **Office** — физический адрес поставщика, к которому могут быть привязаны контакты;
  один поставщик может иметь несколько офисов в разных регионах. См. ADR-0010.
- **SupplierContact** — персональный контакт поставщика: имя, роль, телефон, email;
  опционально привязан к конкретному Office. См. ADR-0010.

### Модуль «Замеры» (ADR-0051)

- **Замер** — задача amoCRM на сделке, учитываемая модулем. Вид (`kind`):
  `primary` («Замер», тип `4410970`), `additional` («Доп. Замер», `4410974`),
  `legacy` («Встреча», тип `2`, у замерщика из карты, пока не закрыт переходный период).
- **Замерщик** — человек из карты в конфиге: аккаунт amo → ключ (`measurer_key`),
  один к одному.
- **`cutover_at`** — переход на новые типы задач и введение поля Site Visit
  Result: 2026-11-09, начало дня, America/New_York.
- **Переходный период** — пока `legacy_meetings_until` не задан, все «Встречи»
  замерщиков считаются замерами. Закрывается установкой этой даты.
- **Site Visit Result** — поле сделки `784029`: исход замера. Одно на сделку,
  поэтому значение привязывается к конкретному замеру правилами атрибуции.
- **Подходящий замер** — без `deleted_at` и со сроком не раньше `cutover_at`; только
  к нему применяется Site Visit Result.
- **Атрибуция** — детерминированная привязка события поля к подходящему замеру
  (`measurements_result_attributions`); **действующий результат** — последнее
  привязанное событие на замере.
- **Drift** — последнее событие поля по сделке расходится со снимком сделки;
  считается, значение не подставляется.
- **Retyped / deleted** — задача вышла из типов замера (или перестала подходить
  под правило `legacy`) / удалена в amo.
- **Исход legacy-замера** (ADR-0053 §3) — для замера со сроком до `cutover_at`
  (`result_source = funnel`): первый непрозрачный выход сделки из воронки
  Measurements в окне замера, по дню New York. `produced` — `142` в Measurements
  или переход в Продажу; `closed` — `143` в Measurements; `not_held` — переход в
  Квалификацию; `no_data` — выхода в окне нет (`window`) или сделка не была в
  Measurements (`never_in_measurements`). Замеры не раньше `cutover_at` идут по
  Site Visit Result (`site_visit`).
- **Окно замера** — от дня замера до ближайшего более позднего дня с замером на
  той же сделке (не включая его); у последнего дня верхней границы нет.
- **Прозрачный выход** — выход в Квалификацию/142 с возвратом в Measurements в
  тот же день New York (автоматика amo); исходом не считается.
- **Группа дублей** — замеры одной сделки в один день New York у одного
  `measurer_key` (`NULL` — тоже ключ). Основной — первый по
  (`scheduled_at`, `task_id`), остальные `is_duplicate`; метрики считают группу
  одним замером.
- **Проведённый замер** (M1) — выполненная группа с исходом не `not_held`
  (`funnel`) или с действующим результатом не `declined` (`site_visit`).
- **Замерный день** (M3) — дата New York с хотя бы одним проведённым замером; у
  компании — различные даты по всем замерщикам.
- **Грант** — запись в `measurements_user_access`, дающая доступ к модулю
  (логическая роль `measurements_viewer`), не значение `User.role`.
- **Watermark** — момент, с которого поток читает amo в следующем окне
  (с перекрытием 2 минуты); сдвигается только после успеха всего окна.
- **Сверка** — ночной (03:30 New York) полный пересчёт со списком задач и сделок
  из amo; **предохранитель** прерывает её без записи, если удаление затронет
  больше 5% строк.

## Именование

- Технический репозиторий/система: `procurement-allocator`.
- Название в интерфейсе (UI) может отличаться — зафиксируй финальное здесь после решения,
  чтобы не расходилось между кодом, документами и тем, что видит пользователь.
